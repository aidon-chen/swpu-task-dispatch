# PRD · 日程总览（统一日历视图）

> 版本：v1.0 ｜ 日期：2026-08-26 ｜ 状态：待评审
> 需求来源：用户（2026-08-26）「可以看到每个成员的空余时间，还有就是看未来和过去每一天的活动之类的安排」→ 小程序内新增模块（已确认）
> 关联：`getTasks`(M9 date 范围) / `getDutyRecords`(值班) / `getDutySchedule`(成员可用性)

## 1. 概述

### 1.1 背景与痛点
- 系统的"安排"分散在三个页面：任务（index）、值班（duty-schedule 本周值班）、成员可用性（duty-schedule 日历矩阵），**没有一个地方能同时看到"某天有什么安排、谁有空"**。
- 主任排任务时需跨页面拼信息：先看值班表避开值班日、再看可用性矩阵找空闲成员、最后查任务排期——低效且易漏。

### 1.2 目标与非目标
- **目标**：① 一个统一日历视图，选中某天可看该天**任务 + 值班 + 成员空余**；② 可翻看**过去与未来**任意一天/月份；③ 成员空余时间一目了然（空闲/忙/不可用/值班冲突）；④ 入口在小程序内、复用现有用户/权限。
- **非目标**：不做个人自定义日程的新增/编辑（本期仅聚合展示，数据仍由任务/值班/状态三个入口产生）；不做提醒推送（沿用现有任务 2h 提醒）；不改动三套底层数据。

## 2. 数据源与聚合

| 数据源 | 字段 | 用途 |
| --- | --- | --- |
| `tasks`（任务） | startTime / title / type / status / assignedTo | 当天有哪些任务 |
| `duty_records`（值班） | date / slot / team / name | 当天谁值班 |
| `duty_schedule` + `user_status`（可用性） | userId × date × status；weeklySchedule | 当天成员空余（available/busy/unavailable） |

**聚合规则（只读叠加，不写库）**：
- 某天视图 = 当天任务列表 + 当天值班列表 + 成员空余矩阵（含"值班中"标记）。
- 成员"空余"判定：`user_status=available` **且** 当天无任务（assignedTo 含自己且当天 startTime）**且** 当天无值班记录（姓名匹配）→ 视为"真正空闲"；有任务或值班 → 标记冲突（任务中 / 值班中）。
- 姓名匹配：`duty_records.name` ↔ `users.name`（与值班表导入一致）；匹配不到不影响展示。

## 4. 页面设计（pages/schedule/schedule）

```
[📅 本周值班安排 · 5 天 ▸]     ← ① 最顶部：可折叠完整值班表（默认收起，
  ▼ 展开后：                     点击标题展开周一~周五全表 + 导入/清空按钮，
  周一 1-2节 视觉中心：蔡江豪、李可欣｜…     与值班表页交互一致，仅主任可导入）
  …（周二~周五）                  ）
[2026年 8月]          ◀ ▶          [回到今天]
┌─────────────────────────────────────────┐
│ 日 一 二 三 四 五 六                     │  ← ② 月历（选中天高亮）
│       1  2  3  4  5  6  7               │
│       8 ...(今天描边)                    │
└─────────────────────────────────────────┘
▼ 8月26日（周三）的活动                       ← ③ 当天三区聚合
【任务】14:00-16:00 运动会拍摄（进行中）
【值班】1-2节 视觉中心：蔡江豪、李可欣 ｜ 6-7节 视觉中心：何璧君…
【成员空余】👤 8 人空闲 ｜ 值班中 2 人 ｜ 任务中 1 人 ｜ 忙/不可用 3 人
```

- **① 顶部可折叠值班表**（2026-08-26 用户要求）：与值班表页折叠交互一致——默认收起只显示标题+天数摘要，点标题展开周一~周五完整排班与「导入/清空值班记录」按钮（仅视觉中心主任）；无数据时自动展开显示导入提示。数据与值班表页同源（`duty_records`），两个页面看到的内容一致。
- ② 月历：复用现有日历样式，今天描边、选中天高亮、有活动日期带圆点。
- ③ 当天三区：任务（可点进详情）+ 值班（时段×团队×人）+ 成员空余（五态徽章）。
- 成员空余区：头像+姓名+状态徽章（绿=空闲/橙=忙碌/红=不可用/蓝框=值班中/任务中），点击可跳任务详情（可选）。

## 6. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 选中日期在学期外（寒暑假） | 值班/任务可能为空 → 空态提示"当天无安排" |
| 姓名匹配不到 user | 值班列表照常展示（文本），不参与空余判定 |
| 成员同时值班+有任务 | 按"任务中"优先标记（任务比值班更紧急） |
| 大月份（31 天） | 月历网格复用现有 generateCalendar 逻辑 |
| 性能 | 单天数据量小；月度可用性复用 getDutySchedule 一次拉取缓存 |
