# 环境初始化清单（M10-3 · 完整版）

本清单用于在新环境（dev / test / prod）首次搭建时，按顺序完成数据库、索引、初始账号与发布前开关的初始化。
三个环境互相隔离（数据库、云函数、存储互不相通），**每个环境都应独立执行一遍本清单**。

> ⚠️ 生产环境（prod）严禁执行会清空/覆盖已有数据的操作。下方所有步骤均为「幂等 / 仅新增」，可安全重跑。

## 1. 集合创建（幂等，可重复执行）

调用云函数 `initDatabase`（每个环境各跑一次）。该函数在 `REQUIRED_COLLECTIONS` 中列出全部集合，已存在则跳过，**不会删除或覆盖数据**。

需存在的集合（9 个）：

| 集合 | 用途 | 备注 |
| --- | --- | --- |
| `users` | 用户信息（openid / 部门 / 角色 / 学期） | 测试用户带 `testSeed:true` |
| `keys` | 权限密钥（一次性，一密钥一用户） | — |
| `tasks` | 任务 + 任务模板 | M8：`isTemplate=true` 为模板（同集合）；M7：`ratings[]/avgScore` 内嵌（无独立评价集合）；测试任务带 `testSeed:true` |
| `user_status` | 成员出勤状态 | — |
| `locations` | 拍摄机位 | — |
| `notifications` | 通知记录 | M1 消息中心 |
| `duty_schedule` | 值班排班矩阵（userId × date） | M3 |
| `news_cache` | 新闻匹配缓存（按 taskId） | M6 |
| `duty_records` | 值班记录（date × slot × 人，值班表导入） | 2026-08-26 新增 |

> 触发方式：模拟器/真机调 `wx.cloud.callFunction({ name: 'initDatabase' })`，或开发者工具「云开发 → 云函数 → initDatabase → 云端测试」。
> 当前 dev 已执行：`duty_schedule`/`news_cache`/`duty_records` 为 2026-08-26 新建，其余 6 个早已存在。

## 3. 初始主任账号（每个环境）

普通成员由 `login` 自动注册（默认 `role: member`）。首位**视觉中心主任（center_director）**需在环境搭建时落地，可选两种方式：

**方式 A（推荐，走正式密钥流程）：**
1. 用任意已登录账号调用 `generateKey({ role: 'center_director' })` 生成正式密钥。
2. 在目标环境的小程序里「验证密钥」完成绑定，该用户即成为中心主任。
3. 之后主任可继续 `generateKey` 生成摄影部/视频部主任密钥，逐级下放。

**方式 B（紧急/自动化）：**
- 云开发控制台 → 数据库 → `users` → 找到目标用户 → 直接把 `role` 改为 `center_director`、`department` 设为 `''`（中心主任无部门限制）。

> 当前 dev 环境：**已落地**（center_director 陈昱臻，openid `ob6ZS13w2GDZXipobhKFjtTwWfa4`）。
> ⚠️ 测试环境可用 `generateTestKey` 生成 `DEV-` 前缀的可复用测试密钥；**生产环境绝不使用测试密钥**，且其开关发布前必须关闭（见 §5）。

## 4.5 测试数据工具（dev / test 专用）

tabBar 第 5 个「测试」tab → 测试工具中心，提供：

| 工具 | 作用 | 说明 |

| 快速新建测试用户 | 生成 3/6/12 个 member 测试用户 | openid 为 `seed-openid-N` 占位，不冲突；幂等 |

## 7. 部署命令速查

```bash
# 部署全部函数到指定环境
node scripts/deploy-functions.js --env test

# 只部署单个函数（调试用）
node scripts/deploy-functions.js --env test --name createTask

# 先 dry-run 确认命令，不实际执行
node scripts/deploy-functions.js --env prod --dry-run

# 单文件增量上传（重试仍挂时的兜底）
"F:/toolapp2/微信web开发者工具/cli.bat" cloud functions inc-deploy --file index.js

# 直连部署（--paths 必须绝对路径）
"F:/toolapp2/微信web开发者工具/cli.bat" cloud functions deploy --env <envId> --appid wx8fdb0c0acb28ee1a --remote-npm-install --paths "G:/project/workbuddy/任务派发软件/miniprogram/cloudfunctions/<fn>"
```

> 脚本内部只连接 `--env` 指定的单一环境，不会跨环境批量写，符合 M10-2 的隔离要求。
> ⚠️ 部署坑：新函数 package.json 必须声明 `wx-server-sdk: latest`；`--paths` 用绝对路径；首建「Creating 状态」锁直接重试。
