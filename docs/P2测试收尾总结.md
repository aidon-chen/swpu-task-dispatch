## 过程中发现并修复的 2 个生产级 Bug
1. **`getReport` 云函数入口丢失（致命）**：原文件末尾 `module.exports = { computeReport, getDateRange }` 覆盖了上方的 `exports.main`。CloudBase 调用 `module.exports.main` 必为 `undefined` → **该云函数上线即挂**。已改为 `exports.computeReport = ...; exports.getDateRange = ...`，保留 `main` 入口。
2. **`getReport` 成员权限越权泄漏**：成员分支 `deptQuery` 保持 `{}`，会返回**全部用户**统计，违背"成员只看自己"。已改为 `deptQuery._id = currentUser._id`。
