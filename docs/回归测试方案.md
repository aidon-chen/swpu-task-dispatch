## 背景：为什么必须回归

三个环境（dev/test/prod）**共用同一个免费云环境**（同一数据库 + 云函数），体验版与正式版云端逻辑一致，
因此**不需要全量重测**。但以下行为在开关归位后发生了改变，必须针对性验证：

1. 云端不再信任前端 `debugRole` → 鉴权回退到数据库真实角色（越权兜底生效）
2. 前端测试模式关闭 → 调试登录入口消失、test-tools 页变占位
3. tabBar 切换为 custom-tab-bar → 测试 tab 按 `testMode.getStatus().enabled` 显隐

## 常见问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 正式版底部出现「测试」tab | custom-tab-bar 未生效或 `testMode` 读取异常 | 确认 `app.json` 有 `"custom": true`、组件目录为根目录 `custom-tab-bar/`、`utils/testMode.js` 的 `isReleaseEnv()` 正常 |
| 图标显示方块 | 未配 CDN 白名单 | 小程序后台 → downloadFile 合法域名加 `https://tdesign.gtimg.com` |
| 越权调用未被拒绝 | 云函数还是旧版（enabled=true） | 重新部署对应云函数 |
| tab 选中态不跟随 | 页面 onShow 未同步 selected | 确认各 tab 页 onShow 调用 `getTabBar().setData({ selected })` |
