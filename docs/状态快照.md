# 任务派发系统 · 状态快照（2026-07-19 更新）

> 压缩版状态，详细过程见 `.workbuddy/memory/2026-07-19.md` 与各 docs。

## ✅ 已完成模块

### M1 通知系统（已模拟器验证）
- `sendNotification` 写 `notifications` 集合；`getNotifications` / `markRead` 云函数
- `utils/notification.js` + `pages/messages/*`（消息中心）；index/profile 红点

### M2 定时触发器 `scheduleNotify`（每30分钟：任务前2h提醒 + 过期自动完结，靠 `notifiedAt` 防重）

### M3 值班矩阵（✅ 模拟器验证：getDutySchedule 返回成员、matrixRows 已构建）
- `initDatabase` 新增 `duty_schedule` 集合
- 新增 `updateDutySchedule` 云函数（批量 upsert，权限：本人/本部门主任/中心主任；含调试角色信任）
- `getDutySchedule` 读取 `duty_schedule` 填充 `availability`
- `duty-schedule` 页面：预计算 `matrixRows`，单元格按状态着色，主任点击单元格 actionSheet 设状态（乐观更新 + 调云函数）

### M4 正式密钥生成（✅ 模拟器验证：页面加载数据正确、无报错）
- 新增 `generateKey` 云函数（仅中心主任；8 位一次性密钥，不含易混淆字符；testKey:false）
- `pages/key-generate` 完整页面（选角色/部门/数量，生成，点击复制）
- `api.generateKey` 接通

### M5 统计报表（✅ 模拟器验证：页面渲染、无报错）
- 新增 `getReport`（按指派成员聚合任务量/完成率/工时；范围=本人/本部门/全员）
- 新增 `exportReport`（复用 getReport，格式化为纯文本，前端复制到剪贴板）
- `pages/statistics` 重写：去掉缺失的 `chart` 组件，改原生条形图 + 明细列表；`api.getReport/exportReport` 接通

### M6 新闻匹配（✅ 模拟器验证：页面/web-view 加载无报错）
- 新增 `crawlNews`（axios+cheerio；关键词加权评分 标题60%+正文40%；7天过滤；写 `news_cache`）
- 新增 `getNewsCache`（读缓存，24h 过期）
- `initDatabase` 新增 `news_cache` 集合
- `api.crawlNews/getNewsCache` 接通；新增 `pages/web-view/web-view`（已注册 app.json）
- ⚠️ 爬虫依赖外网 + 业务域名白名单；当前 `DEFAULT_SOURCE` 为占位，需在后台配置真实新闻源

### M8 任务模板（✅ 前端模拟器验证：create-task 页面渲染/模板开关/模板名输入/模板选择弹层均正常，无 console error）
- `tasks` 集合新增 `isTemplate` / `templateName` / `ownerDepartment` 字段
- `createTask` 改造：支持 `isTemplate` 存为模板（免时间/人员校验、不推送通知）；支持 `fromTemplateId` 从模板实例化（事件字段覆盖模板字段）
- `getTasks` 默认查询排除 `isTemplate:true`（模板不进普通列表与统计）
- 新增 `getTemplates` 云函数（主任及以上；部门主任看本部门+跨部门，中心主任看全部）
- `create-task` 页面：新增「存为模板」开关 + 模板名输入、「从模板创建」弹层（选模板预填表单，时间/人员留空）
- `api.getTemplates` 接通

### M10 三环境分离（代码/配置完成，待填真实 test/prod 环境 ID）
- M10-1 `env.js` 实装：环境 ID 抽取到单一可编辑文件 `config/env.ids.js`；`getEnv()` 按 `envVersion`（develop/trial/release）切换 dev/test/prod；新增开发期本地 storage 覆盖 `td_envOverride`
- M10-2 部署脚本 `scripts/deploy-functions.js`：一条命令部署到指定单一环境（`--env test|prod`，支持 `--name` 单函数、`--dry-run`），绝不跨环境
- M10-3 初始化清单 `docs/环境初始化清单.md`：各环境集合创建（initDatabase，幂等）、推荐索引、初始主任落地方式、发布前测试开关归位检查
